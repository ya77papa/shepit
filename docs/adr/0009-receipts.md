# ADR 0009: «Доставлено» і «переглянуто»

## Рішення

Позначки під вихідними повідомленнями (варіант A — галочки):

| Позначка | Значення |
|---|---|
| годинник | надсилається |
| одна галочка | сервер прийняв, отримувач ще не забрав |
| дві сірі | доставлено на пристрій отримувача |
| дві кольорові | переглянуто (бесіда відкрита на екрані) |
| знак оклику | не надіслано — натиснути, щоб повторити |

- Підтвердження — звичайне зашифроване повідомлення `{"t":"receipt","ids":[…],"s":"d"|"r","g"?,"v":1}`
  від отримувача до відправника. Сервер не відрізняє його від інших конвертів.
- Конверт підтвердження позначений `wake: "quiet"`: сервер не будить отримувача Web Push-сповіщенням.
- «Доставлено» надсилається пакетом після кожного забору пошти; «переглянуто» — коли бесіда відкрита
  на екрані (на Android — застосунок на передньому плані й не заблокований).
- Налаштування «Повідомляти про перегляд» (за замовчуванням увімкнено). Як у Signal: вимкнеш —
  не повідомляєш і сам не бачиш чужих «переглянуто». «Доставлено» працює завжди.
- Групи: дві галочки, коли доставлено всім поточним учасникам; підказка показує «доставлено N з M».
- Стара історія (до оновлення) і відновлена з резервної копії вважаються переглянутими —
  підтвердження за минуле не розсилаються.
