# ADR 0011: Без веб-версії чату

## Рішення

Публічний веб-сервер Шепоту більше не роздає чат-клієнт. Лишається:

- **Сторінка завантаження** (`/`): кнопка «Завантажити APK» →
  `github.com/ya77papa/shepit/releases/latest/download/shepit.apk` (CI кладе в кожен реліз
  копію під сталою назвою), інструкція встановлення, відбиток сертифіката підпису.
- **Запрошення та посилання на канал** (`/#i=…`, `/#add=…`, `/#c=…`): пояснення й кнопка
  «Відкрити в Шепоті» — завдяки App Links (`assetlinks.json`) посилання відкривається в застосунку;
  код запрошення показано окремо.
- **Перехід зі старої веб-версії:** якщо в браузері лишився акаунт, сторінка пропонує зберегти
  зашифровану резервну копію (той самий формат, що відновлює Android) і видалити акаунт з браузера.
  Новий service worker чистить кеші старої версії, знімає себе й перезавантажує вкладки.
- **Адмінпанель** (`/admin/`).

Чат-клієнт лишається в репозиторії (`clients/web`, `npm run build:test` → `dist-test`) лише як
інструмент наскрізних тестів протоколу; публічна збірка (`npm run build`) не містить його коду.

## Чому

Веб-клієнт завантажує код із сервера при кожному відкритті. Хто захопить сервер, може непомітно
підмінити код і забрати ключі — тобто обійти наскрізне шифрування. APK підписаний ключем, якого
сервер не має. До того ж кожну функцію доводилося робити двічі.

## Наслідки

- Немає клієнта для iPhone і комп'ютера. Десктоп-застосунок (підписані збірки) — відкладено на майбутнє.
- Web Push на сервері лишається (не заважає), але нових веб-підписок не буде.
