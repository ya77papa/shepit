# ADR-0005. Застосунок для Android

Дата: 2026-11-16 · Статус: прийнято

## Контекст
Веб-версія має межі, яких не обійти: тихий дзвінок, екран не прокидається на заблокованому
телефоні, немає вибору «до вуха / гучний». Код веб-клієнта завантажується з сервера щоразу.

## Рішення
- **Ядро — те саме Rust-ядро** (`clients/android-core`, UniFFI 0.32 → Kotlin через JNA).
  Криптографія (libsignal: PQXDH, Double Ratchet, sealed sender) не дублюється в Kotlin.
- **UI — Kotlin + Jetpack Compose** (`clients/android`). Compose Multiplatform для десктопу —
  пізніше, коли з'явиться спільний UI-модуль.
- **Формат повідомлень і резервних копій — спільний з веб-версією**: `{"v":1,"t":…}`,
  PBKDF2-SHA256 600k + AES-256-GCM. Копію з браузера можна відновити на телефоні і навпаки.
- **Ключі на пристрої**: стан акаунта зашифрований AES-GCM ключем з Android Keystore;
  хмарне резервування й перенесення між пристроями вимкнені.
- **Дзвінки**: WebRTC (stream-webrtc-android), лише через TURN-ретранслятор, без trickle ICE —
  сумісно з веб-клієнтом. Звук — режим зв'язку, за замовчуванням динамік біля вуха,
  гарнітура має пріоритет; датчик наближення гасить екран.
- **Вхідний дзвінок** — сповіщення CallStyle з full-screen intent: екран вмикається і
  показується поверх блокування, звучить системна мелодія дзвінка.
- **Пробудження**: поки що власний фоновий сервіс (foreground service, `remoteMessaging`)
  тримає SSE-з'єднання з сервером — працює без сервісів Google. FCM (основний) та
  UnifiedPush (опція) — наступний крок; FCM потребує проєкту Firebase.
- **Мінімальна версія** Android 8.0 (API 26).
- **Збірка**: GitHub Actions (`android.yml`) збирає APK, підписує ключем із секретів
  (`SHEPIT_KEYSTORE_B64`, `SHEPIT_KEYSTORE_PASSWORD`) і публікує в Releases разом з
  SHA-256 файлу і відбитком сертифіката. Втрата ключа = неможливість оновлення поверх
  встановленої версії, тому ключ зберігається ще й офлайн у власника.

- **Оновлення**: застосунок раз на 12 год (можна вимкнути) перевіряє GitHub Releases,
  завантажує APK, звіряє SHA-256 з опублікованим GitHub і передає системному встановлювачу
  (PackageInstaller). Android встановлює лише APK з тим самим підписом.

## Наслідки
- APK ~40 МБ (бібліотеки WebRTC і ядра для трьох архітектур); пізніше — розбиття за ABI.
- Перевірка ядра: `CoreInteropTest` (JVM + хост-збірка ядра проти живого сервера).
