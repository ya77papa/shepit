# План розробки

## Етап 0. Фундамент ← ми тут
- [x] Ліцензія: AGPL-3.0
- [x] Клієнти: Kotlin + Compose Multiplatform
- [x] Назва: Шепіт (Shepit)
- [ ] ADR-0001: базова архітектура (стек, ідентичність, транспорт) — чернетка готова
- [~] ADR-0002: криптографія — 1:1 на libsignal вирішено; групи (Sender Keys vs OpenMLS) — відкрито
- [ ] ADR-0003: формат конверта повідомлення
- [x] Каркас Rust workspace у `core/`, `server/`, `clients/cli/`
- [x] Docker-образ сервера (GitHub Actions → ghcr.io) і docker-compose
- [x] Вихід в інтернет: VPS (nginx + Let's Encrypt) — див. docs/deploy.md
- [x] Прототип: два CLI-клієнти обмінюються зашифрованим повідомленням через сервер (PQXDH + Double Ratchet)
- [x] Sealed sender: сервер не бачить відправника
- [x] Автентифікація запитів підписом ключа ідентичності

## Етап 1. MVP
- [x] Веб-клієнт (Rust-ядро у WASM + Svelte) на https://shepit.razom.isroot.in — 2026-11-15
- [x] Веб: посилання-запрошення, QR, онбординг; зашифрована резервна копія ключів
- [x] Сервер: ключі й черги в SQLite (переживають перезапуск); клієнти самі перепубліковують ключі
- [x] Веб: PWA (встановлення, офлайн-оболонка), оновлення за згодою, хеш збірки в CI і version.json
- [ ] Веб: повністю відтворювана збірка (той самий хеш у будь-кого)
- [x] Миттєва доставка (потік подій SSE)
- [x] Голосові повідомлення
- [x] Голосові дзвінки 1:1 (WebRTC, E2EE-сигналізація, TURN за замовчуванням) — ADR-0004
- [x] Сповіщення про дзвінок, коли застосунок закритий (Web Push)
- [ ] Відео, групові дзвінки
- [x] Застосунок для Android (Kotlin + Compose, ядро Rust через UniFFI) — ADR-0005
- [x] Адмін-панель: режими реєстрації, запрошення, статистика — ADR-0006
- [x] Видалення повідомлень (в себе / у всіх), бесід, контактів; видалення користувачів адміном
- [x] Автооновлення Android-застосунку
- [x] Аватари, групи до 100 учасників, канали (зашифровані й публічні) — ADR-0007
- [x] Блокування Android PIN-кодом і/або відбитком; реакції; панель емодзі; «Поділитися» з інших застосунків
- [x] Фото в бесідах і групах — лише транзитом, без EXIF, недоставлені зникають за 3 дні — ADR-0008
- [ ] Файли й відео (потрібне окреме рішення: P2P або сховище)
- [ ] Пробудження через FCM / UnifiedPush (зараз — фоновий сервіс з постійним з'єднанням)
- [x] Підтвердження доставки: сервер видаляє конверт лише після того, як клієнт його зберіг
- Реєстрація без номера телефону (ключ + нікнейм)
- E2EE чати 1:1 і малі групи: текст, фото, файли
- Кілька пристроїв без «головного» телефона
- Self-hosted сервер (Docker), sealed sender
- Клієнти: Android + десктоп
