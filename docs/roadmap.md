# План розробки

## Етап 0. Фундамент ← ми тут
- [x] Ліцензія: AGPL-3.0
- [x] Клієнти: Kotlin + Compose Multiplatform
- [x] Назва: Шепіт (Shepit)
- [ ] ADR-0001: базова архітектура (стек, ідентичність, транспорт) — чернетка готова
- [~] ADR-0002: криптографія — 1:1 на libsignal вирішено; групи (Sender Keys vs OpenMLS) — відкрито
- [ ] ADR-0003: формат конверта повідомлення
- [x] Каркас Rust workspace у `core/`, `server/`, `clients/cli/`
- [x] Docker-образ сервера (GitHub Actions → ghcr.io) і docker-compose для SRV
- [x] Вихід в інтернет: VPS (nginx + Let's Encrypt) → Tailscale → SRV — див. docs/deploy.md
- [x] Прототип: два CLI-клієнти обмінюються зашифрованим повідомленням через сервер (PQXDH + Double Ratchet)
- [x] Sealed sender: сервер не бачить відправника
- [x] Автентифікація запитів підписом ключа ідентичності

## Етап 1. MVP
- [x] Веб-клієнт (Rust-ядро у WASM + Svelte) на https://shepit.razom.isroot.in — 2026-11-15
- [ ] Веб: PWA з оновленням лише за згодою, бекап ключів, відтворювана збірка
- Реєстрація без номера телефону (ключ + нікнейм)

- Кілька пристроїв без «головного» телефона

- Клієнти: Android + десктоп
